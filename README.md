# AI Images Test

A project dedicated to testing and comparing different AI image generation models using the **same prompt**.

## Purpose

The goal is to see how different AI models interpret the exact same prompt and compare their results.

## Testing Method

- Use the same prompt for every model.
- Save the generated images.
- Compare the results.

## Goal

Explore the differences in image quality, accuracy, details, and how each model interprets prompts.
